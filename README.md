# kitty config

Personal [kitty](https://sw.kovidgoyal.net/kitty/) terminal configuration.

**Theme:** Tokyo Night
**Font:** MesloLGS NF
**Shell:** zsh

## Installation

> Requires [kitty](https://sw.kovidgoyal.net/kitty/) and [MesloLGS NF](https://github.com/romkatv/powerlevel10k#fonts) font installed.

```sh
git clone git@github.com:sthitapati/my-kitty-config.git ~/.config/kitty
```

If `~/.config/kitty` already exists, back it up first:

```sh
mv ~/.config/kitty ~/.config/kitty.bak
git clone git@github.com:sthitapati/my-kitty-config.git ~/.config/kitty
```

Restart kitty after cloning.
